# Responsividade do MediFlow

A interface foi ajustada para diferentes tamanhos de tela.

- Desktop: menu lateral completo e tabelas tradicionais.
- Tablet: menu lateral compacto e formulários adaptados.
- Celular: menu lateral deslizante com botão de abertura.
- Tabelas no celular: viram cards para evitar rolagem horizontal.
- Formulários e botões: passam para uma coluna em telas pequenas.
- Dashboard: cards se reorganizam conforme a largura disponível.
- Login e cadastro: layout adaptado para telas pequenas.
- Toasts e campos: largura limitada à tela para não causar overflow.
